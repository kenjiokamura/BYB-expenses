# BYB 立替精算

マネージャーが立替の金額とレシート写真を登録し、会計係が返済の確認・記録、会計Excel用の表、勘定科目ごとの円グラフを使えるアプリです。
GitHub Pages（画面）と Firebase（データの保存）で動かします。どちらも無料の範囲で足ります。

マネージャーはアカウントを作りません。会計係から送られたリンクを開くだけです。

## 全体の流れ（初回だけ、約30分）

1. GitHub にこのファイルを置いて、公開する
2. Firebase を作って、設定値をコピーする
3. 設定を2つのファイルに書き込む
4. 会計係がチームを作って、リンクを配る

---

## 手順1：GitHub に置く

1. GitHub にログインして、右上の「+」→「New repository」を押す。
2. 名前は何でもよい（例：`byb-expenses`）。**Public（公開）** を選んで「Create repository」。
   - 無料で GitHub Pages を使うには、Public が必要です。
   - 公開されるのはコードだけです。立替のデータは Firebase に入り、合言葉がないと読めません。
3. 作ったリポジトリの画面で「uploading an existing file」を押し、次の3ファイルをドラッグして「Commit changes」。
   - `index.html`
   - `firebase-config.js`（手順3で書き換えてから、もう一度アップロードします）
   - `icon-180.png` と `icon-192.png`（黒と黄色の縞模様のアイコン。`icon-512.png` は予備です）
   - `README.md`（置かなくても動きます）
   - `firestore.rules` は GitHub に置く必要はありません（手順2で使います）。
4. リポジトリの「Settings」→「Pages」を開き、「Branch」を `main`、フォルダを `/ (root)` にして「Save」。
5. 1〜2分待つと、`https://あなたのGitHub名.github.io/リポジトリ名/` が使えるようになります。このURLを控えておきます。

## 手順2：Firebase を作る

Firebase のコンソール（https://console.firebase.google.com/ ）に、会計係の Google アカウントでログインします。
画面の言葉は更新で変わることがあります。近い名前のボタンを探してください。

1. 「プロジェクトを追加（作成）」を押し、名前（例：`byb-expenses`）を付ける。Google アナリティクスはオフでよい。
2. プロジェクトのトップで「ウェブ」アイコン（`</>`）を押し、アプリのニックネームを付けて登録する。
   - 「Firebase Hosting も設定」はチェック不要です。
   - 表示される `firebaseConfig` の中の **apiKey / authDomain / projectId / appId** を控えます。
3. 左のメニュー「構築」→「Authentication」→「始める」→「Sign-in method」で、次の2つを有効にする。
   - **匿名**（マネージャー用）
   - **Google**（会計係用。サポートメールは自分のアドレスを選ぶ）
4. 同じ Authentication の「設定」→「承認済みドメイン」に、`あなたのGitHub名.github.io` を追加する。
   - これを忘れると、会計係ログインで `auth/unauthorized-domain` というエラーになります。
5. 左のメニュー「構築」→「Firestore Database」→「データベースを作成」。
   - ロケーションは `asia-northeast1`（東京）がおすすめです。
   - モードは「本番環境モード」を選びます。
6. Firestore の「ルール」タブを開き、中身をすべて消して、`firestore.rules` の内容を貼り付ける。
   - ファイルの中の `kenjiokamura619@gmail.com`（`isOwner` の行）を、**最初の会計係の Google アカウントのメールアドレス**に書き換えてから貼り付けます。
   - 「公開」を押します。
   - 次の会計係は、アプリの「管理」画面から追加できます。このファイルの書き換えは要りません。

## 手順3：設定を書き込む

`firebase-config.js` を、テキストエディタ（メモ帳でも可）で開き、次を書き換えます。

- `apiKey` / `authDomain` / `projectId` / `appId`：手順2の2で控えた値
- `treasurerEmails`：会計係の Google アカウントのメールアドレス（`firestore.rules` と同じもの）

書き換えたら、GitHub のリポジトリで `firebase-config.js` を開き、鉛筆アイコンで内容を貼り替えるか、もう一度アップロードして「Commit changes」します。

## 手順4：チームを作ってリンクを配る

1. 合言葉を決めます。**半角の英数字（`-` と `_` も可）で6〜40文字**。推測されにくいものにします（例：`k7Qm2xW9pT4v`）。
2. 次のリンクを、自分のスマホかパソコンで開きます。

   `https://あなたのGitHub名.github.io/リポジトリ名/?t=合言葉`

3. 右上の「会計係ログイン」を押し、Google でログインします。
4. 「この合言葉でチームを作成する」を押します。最初のメンバー8人（門脇・川田・伊達・児玉・申・鈴木・田中・富田）も一緒に登録されます。ここまでが初回の設定です。
5. 手順4の2のリンクを、マネージャーにLINEなどで送ります（アプリの「管理」画面にも、コピーできるリンクがあります）。マネージャーはリンクを開くだけで使えます。

## 使い方

- マネージャー：「登録」で、一覧から自分の名前を選び、購入日・勘定科目・摘要・金額・レシートを入れて送信。勘定科目で「銭湯代」を選ぶと、人数（使った枚数）と、今回買った銭湯券の枚数を入れる欄が出ます（下の「銭湯券」を参照）。一覧にない名前は「名前を追加する」から自分で登録できます。「自分の立替」で返済の状況を見て、返済を受け取ったら「受け取りました」を押す（忘れても、会計係の履歴・記録には先に反映されています）。
- 会計係：「精算」で誰にいくら返すか確認し、渡したら「返済した」を押す。「銭湯券」で、誰が何枚持っているかを見る。「記録」で会計Excelに貼り付ける表をコピーする。「履歴」で年ごとの返済額と勘定科目ごとの円グラフを見る。
- 「ルール・使い方を見る」（画面の上の青い文字）：アプリの使い方（勘定科目の選び方、レシート、銭湯券、返済の受け取り）をまとめたページです。全員が読めて、会計係だけが「このページを編集する」で書き換えられます。毎年、年度の数字などを更新してください。
- 「履歴」タブの下の「月ごとの支出（去年との比較）」（会計係だけ）：今年の数字は、アプリに登録された立替から自動で数えます。「今月（途中）が去年の同月と比べてどうか」「1月からの合計の差」「年末までの支出の予想」が出ます。去年の数字は、会計Excelの「現金出納帳」「預金出納帳」の表を貼り付けて取り込みます（摘要の文章は保存されません）。今年のExcelも取り込めば、「今年の数字の元」で、アプリの登録とExcelを切り替えられます（Excelのほうは残高と、年末の残高の目安も出ます）。アプリの数字は立替だけなので、去年のExcel（立替以外の支払いも含む）より小さく出やすい点に注意してください。年が替わったら、新しい年の表を取り込んでください。
- 支払い方法：登録する金額が1万円以上のとき、「現金で受け取る」（初期設定）か「振込を希望する」を選べます。振込のときは、銀行名・支店名・口座の種類・口座番号・名義を入力します。口座の情報は、会計係だけが「精算」の「口座を見る」で見られ（コピーもできます）、返済を記録すると自動で削除されます。公開リポジトリには口座の情報は入りません（Firestoreの `bankinfo` に、会計係と登録した端末だけが読める形で一時的に保存されます）。
- 「管理」タブの「古いデータの整理」（会計係だけ）：前の年の立替・返済・レシート写真を削除して、容量を空けられます。削除する前に、勘定科目ごとの合計が保存されるので、履歴の円グラフはそのまま見られます。削除は元に戻せません。確認が出ます。銭湯代を含む返済は、銭湯券の計算のため残ります。
- 「マニュアル」タブ（会計係だけ）：会計係の引き継ぎ用のページです。マネージャーには見えません。会計係だけが編集できます。代が替わるときに更新してください。暗証番号やパスワードは書かないでください。
- 会計係の「管理」画面：会計係の追加と取り消し（次の会計係への引き継ぎ）、メンバー（名前の一覧）の追加と削除、マネージャーに送るリンクのコピーができます。
  - 会計係に追加するのは、その人が会計係ログインに使うGoogleアカウントのメールアドレスです。追加された人は、「会計係ログイン」を押すだけで、精算・記録・履歴・管理を使えます。
  - 「最初の会計係」（`firestore.rules` と `firebase-config.js` に書いたアドレス）は、アプリからは外せません。
- 会計係が「返済した」を押すと、すぐに履歴・記録・円グラフに入ります（「受け取り確認まだ」と表示されます）。マネージャーが「受け取りました」を押すと「完了」になります。

## LINE通知（任意）

立替が登録されたとき、会計係のLINEに自動で知らせる仕組みです。手順は `LINE通知のセットアップ手順.md` を見てください（`line-notify.gs` を使います）。設定しなくても、アプリは今までどおり動きます。

## 銭湯券の扱い

銭湯券は10枚単位で買い、1枚 540円（10枚で5,400円）で計算します。単価を変えたいときは、`index.html` の `BATH_UNIT = 540` を書き換えます。

- 銭湯代の登録には、「人数（使った枚数）」と「今回買った銭湯券（0 / 10 / 20…枚）」を入れます。
- 例：10枚（5,400円）を買って5枚使った場合
  - 会計係がマネージャーに返す金額：5,400円（実際に払った額）
  - 会計ファイル（記録）の出金：2,700円（使った5枚 × 540円）
  - 買った人が持っている券：5枚（「銭湯券」タブに出ます。使っていない分は現金として数えます）
- 手持ちの券を使うだけのとき：「買っていない」を選んで人数だけ登録します（金額0円、レシート不要）。記録の出金には、使った枚数分が載ります。
- 履歴の円グラフも、同じ「使った枚数分」で集計します。
- 以前の方法で登録した銭湯代（人数の欄なし）は、これまでどおり、登録した金額がそのまま出金になります。

## スマホのホーム画面に置く（アプリのように使う）

1. **必ず、会計係から送られたリンク（`?t=合言葉` が付いたもの）を、ブラウザで開いた状態**にします。
   - iPhone は Safari、Android は Chrome を使います。LINE の中のブラウザには「ホーム画面に追加」がありません。LINE のリンクは、右下のメニューから「Safari（ブラウザ）で開く」を選びます。
2. iPhone：共有ボタン →「ホーム画面に追加」。Android：右上の「︙」→「ホーム画面に追加」（「アプリをインストール」と出ることもあります）。
3. ホーム画面に、黒と黄色の縞模様のアイコンができます。タップするとアプリのように開きます。
   - 合言葉はリンクの中に入っているので、ホーム画面から開いても、入力し直す必要はありません。
   - iPhone では、Safari とホーム画面のアプリで、保存される情報が別になります。ホーム画面に追加するときは、必ずリンクを開いたまま追加してください。

## 守りについて

- チームのデータは、合言葉を知っている人だけが読み書きできます。合言葉は、リンクを知っている人にだけ渡してください。
- 次のことはルールで守られています。
  - 勘定科目の変更、会計係の確認ボタン、メンバーの削除、会計係の追加と取り消し：会計係（登録したGoogleアカウント）だけ
  - チームの作成：最初の会計係だけ
  - 立替・レシートの削除：登録した端末か会計係
- 合言葉を知っている人どうしは信頼している前提です。マネージャーが他人の登録を読んだり、返済の「受け取りました」を押したりすることは、仕組みの上では防げません。
- 会計係に登録したメールアドレスは、合言葉を知っている人なら（仕組みの上では）読めます。ほかの人に見せたくないアドレスは、登録しないでください。
- 合言葉が漏れたときは、新しい合言葉でチームを作り直します（古いチームのデータは自動では移りません）。

## 無料の範囲について

Firebase の無料プラン（Spark）で使えます。クレジットカードの登録は要りません。
レシート写真は、小さく圧縮してデータと一緒に保存します（1枚あたり数百KB以下）。毎日の練習の氷代くらいの件数なら、無料枠を超えることはまずありません。

## アップデート

画面を直すときは、新しい `index.html` を GitHub のリポジトリに上書きしてください（「Add file」→「Upload files」で同じ名前を上書き）。数分でサイトに反映されます。データは Firebase にあるので、消えません。
ルールが変わった更新のときは、`firestore.rules` の中身を Firebase の「ルール」に貼り直して「公開」も必要です。

## うまくいかないとき

| 表示・症状 | 原因と対処 |
|---|---|
| 「設定がまだ終わっていません」 | `firebase-config.js` の `PASTE_` が残っています。手順3をやり直してください。 |
| 「ログインできません」 | Firebase の Authentication で「匿名」が有効か確認してください。 |
| 会計係ログインで `auth/unauthorized-domain` | 手順2の4の「承認済みドメイン」に `○○.github.io` を追加してください。 |
| 「このGoogleアカウントは会計係に登録されていません」 | 会計係の「管理」画面で、そのメールアドレスが追加されているか確認してください。最初の会計係は、`firebase-config.js` の `treasurerEmails` と `firestore.rules` のメールアドレスが、ログインしたアカウントと同じか確認してください。 |
| 銭湯代を登録しようとするとエラー（`permission-denied`） | Firestore のルールが古いままです。新しい `firestore.rules` を貼り直して「公開」してください（手持ちの券を使うだけの登録は金額0円なので、新しいルールが必要です）。 |
| 名前の一覧が空 | 会計係の「管理」画面で、「初期メンバーを登録する」を押してください（新しくチームを作ったときは、自動で登録されます）。 |
| 「接続できません」（エラー `permission-denied`） | Firestore のルールが公開されていません。手順2の6をやり直してください。 |
| 「この合言葉のチームがありません」 | 合言葉が違うか、チームが未作成です。会計係が手順4をやってください。 |
| 画面を直したのに古いまま | ブラウザを再読み込みしてください（スマホは、タブを閉じて開き直す）。 |
